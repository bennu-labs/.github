# Bennu · 贝努鸟

> *From Nun's waters it rose and gave the first cry.*
>
> 从努恩的水面升起，鸣出创世的第一声。

古埃及赫利奥波利斯（太阳城）的圣鸟，苍鹭形象，被视为太阳神的灵魂化身（ba）。

## 神话

### 一、创世：虚空中的第一声

太初之时，天地未开，只有 **Nun（努恩）**——无边无际的原初之水。

**Bennu** 从水面飞起，落在第一块升起的陆地 **Benben（原初土丘）** 上，发出第一声鸣叫——创世由此开始。

它是太阳神 Atum / Ra 的灵魂化身，因此常被描绘在太阳船上，随太阳掠过天空。

### 二、循环：每日与时代的重生

- **每日**：傍晚，它与太阳一同沉入 Nun 的水域、穿越冥界；黎明时分从水中升起，获得新生。
- **时代**：传说它每隔五百年飞回太阳城，在圣树上焚身，再从灰烬中重生（后世也把它与约 1461 年的天狼星历法周期相联系）。

希腊人将 Bennu 与「凤凰」（Phoenix）相提并论——"浴火重生"的形象正是从这里流传下去。
